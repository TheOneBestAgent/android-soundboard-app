# Story 0.2: Database Setup & Migration System - Brownfield Addition

## User Story

As a **developer**,
I want **SQLite database setup with Prisma ORM and migration system**,
So that **I can store and manage soundboard data with proper schema versioning and data integrity**.

## Story Context

**Existing System Integration:**

- Integrates with: Express.js server from Story 0.1
- Technology: SQLite 3.40+, Prisma ORM, TypeScript
- Follows pattern: Database-first design with migration-based schema management
- Touch points: Server models, API routes, data persistence layer

## Acceptance Criteria

**Functional Requirements:**

1. SQLite database configured with Prisma ORM integration
2. Database schema matches the defined schema in fullstack-architecture.md
3. Migration system for schema versioning and updates
4. Connection pooling and query optimization
5. Database seeding for development and testing

**Integration Requirements:**

6. Database models integrate with Express.js server routes
7. Prisma client configured for TypeScript type generation
8. Database file location follows desktop-server architecture

**Quality Requirements:**

9. Database migrations run successfully
10. Connection handling includes proper error management
11. Database operations are covered by unit tests

## Technical Notes

- **Integration Approach:** Prisma ORM with SQLite provider for local file-based storage
- **Existing Pattern Reference:** Standard Prisma setup with migration workflow
- **Key Constraints:** Must support concurrent access from mobile app and desktop server

## Database Schema (Core Tables)

```sql
-- Users and Authentication
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  email TEXT UNIQUE,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Sound Buttons
CREATE TABLE sound_buttons (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  name TEXT NOT NULL,
  file_path TEXT NOT NULL,
  duration REAL,
  volume REAL DEFAULT 1.0,
  pitch REAL DEFAULT 1.0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

-- Soundboard Grids
CREATE TABLE soundboard_grids (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  name TEXT NOT NULL,
  layout_config TEXT, -- JSON configuration
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

-- Audio Files
CREATE TABLE audio_files (
  id TEXT PRIMARY KEY,
  filename TEXT NOT NULL,
  file_path TEXT NOT NULL,
  file_size INTEGER,
  duration REAL,
  format TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## Migration Commands

```bash
# Generate Prisma client
npm run db:generate

# Create and apply migration
npm run db:migrate

# Reset database (development)
npm run db:reset

# Seed database
npm run db:seed

# View database in Prisma Studio
npm run db:studio
```
