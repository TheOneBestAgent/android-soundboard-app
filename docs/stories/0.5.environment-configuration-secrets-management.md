# Story 0.5: Environment Configuration & Secrets Management - Brownfield Addition

## User Story

As a **developer**,
I want **secure environment configuration and secrets management for the desktop server**,
So that **I can safely manage API keys, database connections, and environment-specific settings across development, testing, and production**.

## Story Context

**Existing System Integration:**

- Integrates with: All previous infrastructure stories (0.1-0.4)
- Technology: dotenv, node-config, crypto for encryption
- Follows pattern: Standard Node.js environment configuration with security best practices
- Touch points: Server startup, database connections, external API integrations, logging

## Acceptance Criteria

**Functional Requirements:**

1. Environment-specific configuration files (development, testing, production)
2. Secure secrets management with encryption for sensitive data
3. Environment variable validation and type checking
4. Configuration hot-reloading for development
5. Default fallback values for all configuration options

**Security Requirements:**

6. API keys and secrets are never committed to version control
7. Production secrets are encrypted at rest
8. Configuration validation prevents startup with invalid settings
9. Sensitive data is masked in logs and error messages

**Integration Requirements:**

10. Configuration integrates with server startup (Story 0.1)
11. Database connection settings work with Prisma (Story 0.2)
12. Electron app settings are properly configured (Story 0.3)
13. Build pipeline respects environment configurations (Story 0.4)

## Technical Notes

- **Integration Approach:** Layered configuration with environment variables, config files, and encrypted secrets
- **Existing Pattern Reference:** Standard Node.js configuration management with security enhancements
- **Key Constraints:** Must support local development while maintaining production security

## Configuration Loader Implementation

```typescript
// src/config/index.ts
import config from 'config';
import { validateConfiguration } from './validator';
import { decryptSecrets } from './secrets';
import { ConfigSchema } from './types';

export class ConfigurationManager {
  private static instance: ConfigurationManager;
  private config: ConfigSchema;

  private constructor() {
    this.loadConfiguration();
  }

  public static getInstance(): ConfigurationManager {
    if (!ConfigurationManager.instance) {
      ConfigurationManager.instance = new ConfigurationManager();
    }
    return ConfigurationManager.instance;
  }

  private loadConfiguration(): void {
    try {
      // Load base configuration
      const baseConfig = config.util.toObject();
      
      // Decrypt secrets if in production
      const configWithSecrets = process.env.NODE_ENV === 'production' 
        ? decryptSecrets(baseConfig)
        : baseConfig;
      
      // Validate configuration
      this.config = validateConfiguration(configWithSecrets);
      
    } catch (error) {
      console.error('Failed to load configuration:', error);
      process.exit(1);
    }
  }

  public get<T = any>(key: string): T {
    return config.get<T>(key);
  }

  public has(key: string): boolean {
    return config.has(key);
  }

  public getAll(): ConfigSchema {
    return this.config;
  }
}

export const appConfig = ConfigurationManager.getInstance();
```

## Secrets Management

```typescript
// src/config/secrets.ts
import CryptoJS from 'crypto-js';
import fs from 'fs';
import path from 'path';

const SECRETS_DIR = path.join(process.cwd(), 'secrets');
const ENCRYPTION_KEY = process.env.SECRETS_ENCRYPTION_KEY;

export function encryptSecret(value: string): string {
  if (!ENCRYPTION_KEY) {
    throw new Error('SECRETS_ENCRYPTION_KEY environment variable is required');
  }
  
  return CryptoJS.AES.encrypt(value, ENCRYPTION_KEY).toString();
}

export function decryptSecret(encryptedValue: string): string {
  if (!ENCRYPTION_KEY) {
    throw new Error('SECRETS_ENCRYPTION_KEY environment variable is required');
  }
  
  const bytes = CryptoJS.AES.decrypt(encryptedValue, ENCRYPTION_KEY);
  return bytes.toString(CryptoJS.enc.Utf8);
}

export function decryptSecrets(config: any): any {
  const secretsFile = path.join(SECRETS_DIR, `${process.env.NODE_ENV}.encrypted.json`);
  
  if (!fs.existsSync(secretsFile)) {
    return config;
  }
  
  try {
    const encryptedSecrets = JSON.parse(fs.readFileSync(secretsFile, 'utf8'));
    const decryptedSecrets = {};
    
    for (const [key, value] of Object.entries(encryptedSecrets)) {
      if (typeof value === 'string') {
        decryptedSecrets[key] = decryptSecret(value);
      }
    }
    
    return { ...config, ...decryptedSecrets };
  } catch (error) {
    console.error('Failed to decrypt secrets:', error);
    return config;
  }
}
```

## Setup Scripts

```javascript
// scripts/setup-env.js
const fs = require('fs');
const path = require('path');
const crypto = require('crypto');

function generateSecretKey(length = 32) {
  return crypto.randomBytes(length).toString('hex');
}

function setupEnvironment() {
  const envFile = path.join(process.cwd(), '.env');
  const exampleFile = path.join(process.cwd(), '.env.example');
  
  if (fs.existsSync(envFile)) {
    console.log('.env file already exists');
    return;
  }
  
  if (!fs.existsSync(exampleFile)) {
    console.error('.env.example file not found');
    process.exit(1);
  }
  
  let envContent = fs.readFileSync(exampleFile, 'utf8');
  
  // Generate secure keys
  const secretsKey = generateSecretKey();
  const sessionSecret = generateSecretKey();
  const jwtSecret = generateSecretKey();
  const dbEncryptionKey = generateSecretKey();
  
  // Replace placeholder values
  envContent = envContent
    .replace('your-secrets-encryption-key-here', secretsKey)
    .replace('your-session-secret-here', sessionSecret)
    .replace('your-jwt-secret-here', jwtSecret)
    .replace('your-32-character-encryption-key-here', dbEncryptionKey);
  
  fs.writeFileSync(envFile, envContent);
  console.log('✅ .env file created with secure keys');
  console.log('⚠️  Please update API tokens and other configuration values');
}

if (require.main === module) {
  setupEnvironment();
}

module.exports = { setupEnvironment, generateSecretKey };
```
